## 方向变更

本轮仅针对网站。此前 05、06 图的独立弹窗工作台不再是网站期望方向，保留为过程记录；不据此修改小程序已完成的非聊天流程。04 首页的暖白、克制图标与轻量布局仍是视觉参考，但两种工具入口将统一为可输入文字、附图或粘贴图片的创作输入。

## 页面与路径

首页继续保留灵感广场。发送想法或参考图后进入独立全页聊天，图库「带图开始创作」可带入参考图。左侧统一新建创作和会话历史；中央为当前会话；底部固定统一输入，不再有文字/图片两个独立工具工作台或弹窗。

图中示例为：用户发送粉色唇膜参考图 → 版本1提示词 → 用户要求保留构图、改奶油白背景与自然光 → 展示版本2。图片只是用户参考素材；AI输出是提示词文本。原图及旧结果不被新回复覆盖。

## 结果操作

- 同一条结果卡标明版本与当前语言；切换中文/English、编辑与复制始终作用于该版本。
- 旧版本可折叠并展开，最新版本保持可见。复制按钮明确当前语言。
- 图片会话显示画面拆解；从纯文字想法生成时显示创作要点。
- 手动编辑仅更新本版本当前语言并展示保存状态，不触发模型。离开或切换会话时保护未保存内容。
- 快捷调整只填写草稿，用户确认发送后才发起新生成。
- 发送时展示真实任务状态、阻止重复提交；失败保留输入，状态不明优先恢复既有任务；切换会话或页面后可从历史恢复。
- 追加图片时明确是补充还是替换当前参考素材，发送前可移除；图片与文本来源、生成结果版本需要保持对应。
- 会话和图片为当前账户私有，不自动投稿。退出或换账号清理旧身份私密草稿。

## 实现边界

这次图稿不是现有后端已支持连续对话的证明。实现需要另行核对与设计会话、消息、上下文、结果版本、引用素材、限流和任务幂等；现有单次文本/图片任务不能仅改成气泡就声称支持多轮。
