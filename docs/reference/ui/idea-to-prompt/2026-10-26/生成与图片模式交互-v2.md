# 网站 v2 生成与图片模式交互

日期：2026-10-26。状态：供用户评审的设计稿。延续 04 新版轻量浅色首页，不是此前被否定的 03 浅色稿。没有实施网站业务代码或发布。

## 文字生成

1. 点击生成后打开同一创作面板，保留原想法、用途和风格；右侧展示真实任务阶段与骨架，不显示虚构百分比。
2. 生成完成右侧展示完整提示词与创作要点，支持中文/English、手动编辑、当前语言复制与私有历史。
3. 点击编辑后只编辑当前语言，隐藏语言切换；取消返回原结果，保存成功后更新历史和保存提示。保存失败保留草稿。

## 图片模式

1. 首页切换到图片模式，保留同样位置、宽度、历史和折叠控件；输入框替换为横向轻量选图区。支持点击选择、拖拽和粘贴，JPEG/PNG/WebP、单张不超过 5MiB。
2. 选择后只本地预览。显示缩略图、更换和移除；点击生成才上传并创建任务。上传或分析失败保留参考图并提供重试。
3. 生成后仍使用同一双栏面板，左侧为原参考图，右侧为中英提示词和画面拆解。图片生成过程复用文字等待状态，但左侧保留图片，依实际阶段显示上传/分析，不把尚未上传误称已进入模型生成。
4. 图库转提示词按钮把作品图带入首页的图片模式并展开、滚动到创作区，不自动调用模型；点击生成后才分析。

## 共用边界

- 返回广场或关闭面板不取消已创建的任务；从历史恢复。创建结果未知先查询已有任务，重复点击和重试不重复创建付费调用。
- 修改来源不自动重新生成。旧结果和新来源不一致时，必须提示结果对应上次输入，不能错配。
- 切换中英、复制、手动编辑、查看历史均不调用模型。图片与结果默认为当前身份私有，不自动投稿。
- 未保存修改在关闭、切换历史、换图或重新生成前保护；账号切换清理旧身份的私密草稿。
- 不新增聊天、生图、视频、付费或供应商模型选择能力。
- 图中照片、文本、保存状态均为示例。正式实现中沿用现有主题 token 和控件；图片稿中的绿色保存勾选只是绘图偏差，统一使用现有中性状态色，不新增绿色主题。图库图片必须保留真实比例，示意图中的比例变化不构成裁切要求。
