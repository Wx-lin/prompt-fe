# 网站统一提示词创作：实现与本地验证记录

记录日期：2026-10-27。设计基准为本目录的 `12-首页柔和圆角-提示词创作-v5.png` 与 `08-网站同页图库与聊天-v2.png`。本轮只完成本地开发与验证，不包含部署、推送、生产数据库迁移或真实模型调用。

## 已落地交互与技术栈

- 保留网站原 Logo，头部文字为「提示词创作」，去掉页头通栏分隔线；首页创作框上提，使用 28px 圆角。不增加重复分区大标题。
- 一处创作输入接文字、上传、粘贴、拖入图片或图库参考图。选图只在本地预览，点击发送后才上传和生成。
- 桌面默认五列图库；发送后同页展开左侧三列图库、右侧约 40% 聊天。窄屏为同页纵向聊天与两列图库。保留页面滚动，右栏独立滚动，不把整个首页锁成弹窗。
- 搜索属于图库，与分类、排序、模型筛选同一工具栏；保留快捷键、最近搜索、推荐词、查询参数、详情路由和分页。聊天状态放在筛选导航之外，收起、搜索后可继续上次创作。
- 卡片「带图创作」只选择该作品的公开图片作为草稿，不自动开始生成。详情与复制等既有入口保留。
- 会话包含生成状态、连续修改、历史版本、中英文切换、当前版本编辑与复制、私有历史及删除。账号切换清理私有草稿、引用图与历史，迟到响应不能恢复旧身份内容。
- 深浅主题沿用原主题 token，H5 小屏发布入口使用有可访问名称的加号，避免挤掉完整品牌名称。

前端沿用 Next.js 16.4.2、React 19、TypeScript、next-intl、Base UI、Lucide 与 CSS Modules；后端沿用 FastAPI、PostgreSQL、Redis、SQLAlchemy/Alembic 及独立 Worker。图库布局通过 `GalleryPage` 的 composer/panel slots 集成，不把会话业务塞进图库组件。

## 验证环境与证据层级

新功能浏览器用例是 `e2e/inline-prompt-chat.spec.ts`。它经过真实的 Next BFF、认证、API、SQL、Redis 和 Worker，供应商、邮件验证码及图片对象存储由本地替身替换。`e2e/helpers/prompt-analysis-fixture.py` 每次启动创建随机 PostgreSQL schema 与 Redis 前缀，正常停止只删除自己的数据，不执行 `FLUSHDB`，不读取后端 `.env`，也不请求真实 COS 或模型服务。

本轮先前已验证的桌面/手机 8 条用例涵盖：首页五列/聊天三列/H5 两列、品牌完整、搜索归属图库、无水平溢出、系统暗色；文字生成挂起后收起并搜索、继续生成、双语、人工编辑、基于保存版本续写、重开历史；本地图与图库图显式发送；切账号清私密内容及旧会话跨账号 404。它们是本地浏览器证据，不代表微信真机或线上验收。

2026-10-27 后端最后一轮修改后，旧 fixture 已正常停止清理，新 fixture 在 8036 重启并返回 `{"status":"ok","worker_running":true,"isolated_fixture":true}`。生产构建的最后浏览器复跑为 `inline-prompt-chat.spec.ts` 加 `layout-regressions.spec.ts`，桌面和手机共 **12/12 通过**（54.1 秒）。包含上述全部新功能链路及真实 1280×720 输入区边界。

演示模式的旧回归保持原断言：`search`、`select-field`、`scroll-lock` **26/26 通过**（41.6 秒）；`home` 的直接详情/登录、主题、关闭详情、语言四条场景在桌面和手机 **8/8 通过**（32.1 秒）。另跑新首页浅深主题的截图用例 **2/2 通过**（10.8 秒）。本轮最终浏览器合计 **48 项通过**，其中 12 项为生产构建下的隔离真实接口链路，34 项为演示数据旧回归，2 项为演示首页布局截图；不把三类证据混为真实供应商验收。

主任务最后整仓检查：60 个单测文件 **614 项通过**，覆盖率语句 94.29%、分支 91%、函数 96.2%、行 97.31%；lint、TypeScript、production build 通过。图库相关单测为 11 文件 55 项通过，新增锚点/工具栏/品牌定向覆盖率为行、函数、语句 100%，分支 97.29%。

## 2026-10-27 追加：输入体验与克制动效

本节是上述统一创作功能验收之后的一轮 UI 优化，单独记录新增范围，不把前一轮 48 项宣称为本轮重复执行。

- 输入框移除拖拽角与「支持粘贴」文字，按文字自动增高、最高 208px，超过后在框内滚动；清空恢复初始高度。桌面聚焦提示 Enter 发送、Shift+Enter 换行；触屏提示回车换行、点击发送。
- 同页侧栏使用 240ms 淡入与 12px 位移，桌面两轨 Grid 平滑调整图库宽度，窄屏使用纵向高度过渡。展开/收起只动画公共外壳；被移除的个人内容立即卸载，不缓存旧账号 ReactNode。首页创作区只保存已测量的数字高度做空壳过渡。
- 图库锚点在过渡期间冻结、结束后恢复；用户主动滚动时取消回拉。减少动态效果时跳过高度动画，CSS 沿用全局极短过渡约定，实际没有持续运行动画。
- 窄屏父壳扣除头部高度，子面板填满父壳，避免低视口中的旧固定最小高度裁掉发送按钮。

先补失败单测，再实现。新 `use-gallery-layout-motion` 定向覆盖率为行 100%、分支 85%、函数 92.85%、语句 97.36%。单测覆盖数字高度、延后恢复锚点、实时滚动位置、用户滚动不抢回、快速反转、减少动效切换与卸载清理；旧个人内容从 DOM 立即移除另有组件断言。

本轮新增 [`e2e/composer-motion.spec.ts`](../../../../../e2e/composer-motion.spec.ts) 对现有 `http://localhost:3137/` 匿名执行 **6/6 通过**（32.3 秒）。测试不改预览 API 指向，所有创作 POST 都被拦截并断言为零，没有上传图片或调用真实模型。验证桌面 1280×720、手机 390px，以及 390×420/500 低视口：侧栏淡入和图库宽度存在真实中间态；快速开关后关闭空壳高度为零；减少动态效果没有持续动画；发送按钮在视口内；输入高度、内部滚动、清空、键盘提示和无水平溢出符合预期。
