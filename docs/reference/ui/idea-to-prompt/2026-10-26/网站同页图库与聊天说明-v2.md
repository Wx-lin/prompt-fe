## 本轮变化

07 独立聊天页不再是当前建议。08 保持同一首页和全站页头，图库与聊天是两个平级区域。桌面约60%图库、40%聊天，1600px视口聊天约560–640px；图库三列。只有一条轻分隔线，不以遮罩、弹窗或覆盖式抽屉承载主工作流，也不使用左侧会话导航挤占图库。

## 浏览与创作的连续路径

1. 浏览状态保留完整图库和统一的文字/图片轻输入。点击发送或主动展开创作时，在同一首页原位展开右侧聊天；保留当前搜索、分类、排序和作品锚点。图库从五列自适应为三列，不能回到顶部或重置筛选。
2. 展开后只保留右侧底部一个创作输入；首页原有大输入区收起，避免两处输入互相竞争。
3. 图库「带图创作」将图片加入待发送草稿。选择或带入图片只预览，用户发送后才上传并创建生成任务。当前会话结果对应的参考图在图库中有轻量标识，可点击来源定位原图；新图片不能悄悄替换旧结果的来源。
4. 文字想法、图片输入与后续修改均在同一聊天完成。响应是带版本的双语提示词卡。复制、手动编辑、画面拆解/创作要点、保存状态贴着对应结果；旧版本可折叠回看。
5. 聊天顶部为新建、历史、收起；历史在区域内切换视图，不跳到独立页面。收起恢复完整图库，保留对话、输入和浏览位置。生成中可继续浏览，历史可恢复任务。
6. 聊天与图库分别滚动，输入固定在聊天底部；到达边界不意外带动另一栏。正文和底部操作预留空间，避免被输入框遮住。

## 设计与范围约束

- 暖白、黑字、细边框和现有 Logo；继续复用现有主题与组件。图中文字和作品仅为展示样例。
- 1600px双栏比例为视觉参考。实际实现需验证宽度；聊天不足约520–560px时应改为同页纵向布局，不硬挤三列图库与窄聊天。窄屏布局尚未在本图展示，不声称已验收。
- 每次追问需有明确上文、来源和版本；手动编辑仅改当前版本当前语言。切换语言和复制不调用模型；快捷建议先填入草稿，不自动发送。
- 请求未知状态查询旧任务；失败保留输入；避免重试/重复发送创建重复模型调用。账号切换清理旧身份私密草稿；未保存编辑在离开或换会话前保护。
- 当前只是网站新交互提案，不据此改动小程序已经实现的非聊天流程。会话、上下文和版本后端仍需单独设计与实施。
