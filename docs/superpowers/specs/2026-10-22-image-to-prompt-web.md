# 网站图片转提示词

用户要求先开发网站，完全按照昨天生成的网站UI，不以实测报告页作产品设计。基准为 `docs/reference/ui/image-to-prompt/upload-state-v2.png` 和 `result-state-v2.png`；被否定的独立白色入口不采用。

## 视觉与范围

搜索框右端增加分隔线和扫描图标「反推提示词」入口。保留原搜索、快捷键与图库。打开居中Base UI Dialog，标题「反推提示词」、说明「上传参考图片，提取可编辑的提示词」；左侧约三分之一参考图，右侧「完整提示词 / 画面拆解」，底部左侧语言选择，右侧开始/重新反推/复制。结果文本可编辑，保持图片原比例。主题沿用现有token，暗色对照原稿，浅色沿用现有反转语义；移动端上下排列、不横向溢出。新能力只含图片，不实现图中视频图标/文案，不加入生图/支付/模型选择。

复用Base UI Dialog、Tabs、Select、Button、AlertDialog与既有Lucide图标、上传校验/粘贴排除输入框规则。单图选择与六图投稿的接口和语义不同，独立封装，保持现有上传操作习惯，不新增依赖。

## 功能

选图只做本地预览；点击开始后才上传和创建付费解析任务。JPEG/PNG/WebP≤5MiB；服务端完成真实解码和像素检查。登录沿用原Google/邮箱界面，给现有LoginPage补可选完成/关闭回调，用于原位登录；选图状态保持，不新增登录体系，不把文件/token存localStorage。身份失效后可重新登录，恢复任务查询，不自动重开付费任务。

实际API为 `/api/prompt-assets`、`/api/prompt-assets/{id}`、`/api/prompt-analyses`、`/api/prompt-analyses/{id}`。BFF从HttpOnly Cookie读取JWT，写请求检查Host/Origin，限制流式请求大小、校验UUID、JSON结构和分页参数；不跟随重定向，不透传任意上游错误。202/200/204及幂等键保持原契约，所有私有响应no-store。

创建任务网络错误时保留同一UUID幂等键供主动重试；上传/创建/轮询分别管理。轮询到成功/失败/unknown/404停止，关闭和换图清理旧请求，旧响应不能覆盖当前图。关闭界面不承诺取消供应商调用。中文/英文切换不调模型；编辑自动保存，保存成功才显示已保存，保存失败保留草稿并可重试；并发冲突不静默覆盖。复制当前草稿，失败不得显示成功。

历史以同一面板中的次级视图呈现，通过低调历史入口打开。分页、重开时刷新私有预览、删除并确认；无历史/图过期/失败任务有真实状态。不把临时demo或空示例接口伪造成已解析内容。

## 验收

TDD先覆盖BFF鉴权/CSRF/大小/安全错误/方法与幂等；hook覆盖竞态/轮询/网络重试/编辑；RTL覆盖上传、Tab、语言、复制及登录回调。真实PG/Redis fixture替换供应商完成可重复E2E，桌面1536×1024和390px、深浅主题对照设计。少量实图再核验真实COS/Worker/Qwen及历史。完整lint/typecheck/tests/新增模块专项80%以上coverage/build，并做独立契约与安全审查。此任务不提交、推送或部署。
